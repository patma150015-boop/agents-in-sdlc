Os workshops Primeiros passos são introduções guiadas que ajudam você a explorar o GitHub Copilot sem exigir um aplicativo existente nem um cenário detalhado de desenvolvimento. Cada workshop começa com algo simples, apresenta o produto enquanto você o usa e conduz você por um fluxo de trabalho completo.

Todos os workshops criam o mesmo Space Quiz a partir de uma pasta vazia. Assim, você pode escolher a ferramenta que quer conhecer ou concluir mais de um workshop para comparar como cada uma funciona.

> [!NOTE]
> Estes workshops foram criados por [James Montemagno][james] e adaptados de [First Steps with GitHub Copilot][source-lab], disponível sob a [Licença MIT][source-license].

## Workshops

### [Tour pelo aplicativo GitHub Copilot][first-steps-app]

Crie um Space Quiz colorido a partir de uma pasta vazia e percorra o ciclo de desenvolvimento: crie, refine e teste o aplicativo; registre instruções do projeto; publique-o; planeje o trabalho; implemente issues; revise e mescle um pull request; automatize tarefas recorrentes; e explore uma extensão do Canvas.

### [Primeiros passos com o GitHub Copilot CLI][first-steps-cli]

Use um fluxo de trabalho centrado no terminal: crie e revise diffs antes de o Git gravar qualquer alteração, execute sessões paralelas em worktrees, planeje antes de editar, gerencie o contexto e, depois, crie, mescle e delegue trabalho sem sair do shell.

### [Primeiros passos com o Visual Studio Code][first-steps-vscode]

Use o fluxo de trabalho do editor: desenvolva em um espaço de trabalho, aprimore elementos no navegador integrado, inspecione o contexto, teste antes de o Git gravar qualquer alteração, planeje antes de editar e use as ferramentas do GitHub para trabalhar com issues, pull requests e sessões na nuvem sem sair do VS Code.
